# Dataset — Customer Support Tickets

## Source des données

**Nom :** Multilingual Customer Support Tickets

**Plateforme :** Kaggle

**Lien :** https://www.kaggle.com/datasets/tobiasbueck/multilingual-customer-support-tickets

## Instructions de téléchargement

1. Ouvrir le lien Kaggle.
2. Se connecter à son compte Kaggle.
3. Télécharger le dataset.
4. Décompresser l'archive si nécessaire.
5. Placer le fichier CSV dans ce dossier `data/`.

## Préparation

Pour ce projet, nous utiliserons un échantillon d'environ 10 000 tickets afin de faciliter les premières analyses.

Le fichier de données ne sera pas directement publié sur GitHub. Seules les instructions et la source seront partagées ici.
